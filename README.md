# SOC Analyst Home Lab: SIEM Home Lab with Elastic, EDR, and Atomic Red Team, Incident Response & MITRE ATT&CK Mapping

<img width="1536" height="1024" alt="SOC Project " src="https://github.com/user-attachments/assets/4ae75602-ae98-4f4f-8b95-a9968505fc61" />

Designed and implemented a SOC home lab to simulate real-world blue team operations and threat detection. Built a SIEM environment using the Elastic Stack and Elastic EDR, created custom detection rules and playbooks, simulated attacks with Atomic Red Team, and mapped detections to the MITRE ATT&CK framework.

Designed and implemented a full Security Operations Center (SOC) home lab to simulate real-world blue team operations and threat detection workflows.

The project focused on practical cybersecurity skills including SIEM engineering, incident detection, threat intelligence analysis, and incident response workflows.

# project included:

• Building a SIEM lab environment from scratch using the Elastic Stack

• Integrating Elastic EDR to collect and analyze endpoint telemetry

• Developing custom detection rules and alert logic to identify malicious activity

• Creating incident response playbooks for security investigations

• Simulating adversary behavior using Atomic Red Team to validate detections

• Mapping alerts and attack techniques to the MITRE ATT&CK framework to improve threat visibility
